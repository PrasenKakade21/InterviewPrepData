# Colors, Backgrounds and Gradients

Color is the fastest way to make a page feel intentional, and backgrounds do most of the visual work. CSS gives you color spaces, gradients, multiple layers, and blending — all without images.

The core idea:

```text
visual surface
    ├── color            → text
    ├── background-color → fill
    ├── background-image → image or gradient
    ├── background-size/position/repeat → placement
    └── opacity/blend    → compositing
```

---

# 1. color and background-color

`color` sets text (and `currentColor`) while `background-color` fills the element's padding box. Both accept the same color formats.

```css
.card {
  color: #0f172a;
  background-color: #f8fafc;
}

.card__meta {
  color: #64748b;
}
```

Output:

```text
Dark text on a light gray card; muted metadata.
```

Interview trap: `color` is inherited; `background-color` is not. A child with no background shows the parent's background through it.

---

# 2. background-image and Gradients

`background-image` accepts URLs or gradients. Gradients are images generated by CSS: `linear-gradient()`, `radial-gradient()`, `conic-gradient()`.

```css
.hero {
  background-image: linear-gradient(135deg, #0f172a 0%, #334155 100%);
}

.badge {
  background-image: radial-gradient(circle at 30% 30%, #fde68a, #f59e0b);
}

.conic {
  background-image: conic-gradient(#0f172a 0 25%, #e2e8f0 0 50%, #0f172a 0 75%, #e2e8f0 0);
}
```

Output:

```text
Hero: diagonal dark gradient
Badge: warm radial glow
Conic: four-segment pie pattern
```

Gradient syntax: `linear-gradient(angle, color stop, color stop, ...)`. Add hard stops (`#0f172a 0 25%`) for bands.

---

# 3. background-size, position, repeat and attachment

These properties place and scale the background layer.

```css
.hero {
  background-image: url("/img/hero.jpg");
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
  background-attachment: fixed;
}
```

Output:

```text
Image fills the hero, centered, no tiling, fixed while scrolling.
```

| Property | Common values |
| -------- | ------------- |
| `background-size` | `auto`, `cover`, `contain`, `100% 100%` |
| `background-position` | `center`, `top right`, `20% 80%` |
| `background-repeat` | `repeat`, `no-repeat`, `repeat-x`, `space` |
| `background-attachment` | `scroll`, `fixed`, `local` |

Interview trap: `background-attachment: fixed` is janky on mobile and can hurt performance; prefer a fixed positioned pseudo-element or just `scroll`.

---

# 4. Multiple Backgrounds

Comma-separate layers. The first layer is on top; later layers sit underneath.

```css
.hero {
  background-image:
    linear-gradient(to bottom, rgb(15 23 42 / 0.7), rgb(15 23 42 / 0.9)),
    url("/img/hero.jpg");
  background-size: cover;
  background-position: center;
}
```

Output:

```text
Hero photo with a dark gradient overlay for readable text.
```

Think:

```text
layer 1 (top)    → gradient overlay
layer 2 (bottom) → photo
```

This is the standard "text over image" technique — no extra wrapper element needed.

---

# 5. opacity, color-mix() and currentColor

`opacity` fades the whole element (including children) and creates a stacking context. `color-mix()` blends two colors. `currentColor` reuses the element's text color.

```css
.overlay {
  opacity: 0.6;
}

.button {
  color: #0f172a;
  border: 1px solid currentColor;
}

.tint {
  background: color-mix(in oklab, #0f172a 20%, white);
}
```

Output:

```text
Overlay at 60% (children too); border matches text;
tint is a 20% brand mix with white.
```

Interview trap: use alpha colors (`rgb(... / .6)`) when you want to fade a background without fading the text.

---

# 6. Contrast Basics

Text needs sufficient contrast against its background: 4.5:1 for normal text, 3:1 for large text (WCAG AA). Gradients and images make contrast unpredictable.

```css
.hero__title {
  color: #fff;
  text-shadow: 0 1px 2px rgb(0 0 0 / 0.6);
}
```

Output:

```text
White title remains readable over a busy photo.
```

Better than text-shadow alone: add a solid/gradient overlay behind the text, or a semi-opaque panel. Test with a contrast checker and in forced-colors mode.

---

# Real-World Uses

A hero section layers a photo, gradient overlay, and text using multiple backgrounds.

```css
.hero {
  min-height: 60dvh;
  display: grid;
  place-items: center;
  padding: clamp(2rem, 6vw, 5rem);
  color: #fff;
  background-image:
    linear-gradient(to bottom, rgb(15 23 42 / 0.55), rgb(15 23 42 / 0.9)),
    url("/img/kakade-hero.jpg");
  background-size: cover;
  background-position: center;
}

.hero__title {
  font-size: clamp(2rem, 5vw + 1rem, 4rem);
  text-wrap: balance;
}
```

Output:

```text
Readable hero with photo, overlay, centered scalable title.
```

# Quick Revision

| Concept | Remember |
| ------- | -------- |
| **color** | Text color, inherited |
| **background-color** | Fill behind content |
| **background-image** | URL or gradient |
| **Linear gradients** | Angle + color stops |
| **Radial and conic** | Circular / angle-based |
| **background-size/position** | Scale and place layers |
| **Multiple backgrounds** | First layer on top |
| **opacity** | Whole element + children |
| **color-mix()** | Blend two colors |
| **currentColor** | Reuse text color |
| **Contrast** | 4.5:1 normal, 3:1 large |

## The Mental Model

```text
surface
  ├── text color → color
  ├── base fill → background-color
  ├── layers → background-image (gradient/image, comma-separated)
  │     ├── size → cover/contain
  │     └── position → center/top right
  └── compositing → opacity / blend modes
```

### The 3 things to remember

**1. Overlay for readability:**

```css
background-image:
  linear-gradient(rgb(15 23 42 / 0.7), rgb(15 23 42 / 0.9)),
  url("/img/hero.jpg");
```

**2. currentColor for consistency:**

```css
.button {
  color: #0f172a;
  border: 1px solid currentColor;
}
```

**3. Contrast is non-negotiable:**

```css
.hero__title { color: #fff; }
```

> **Backgrounds are layers — fill, image/gradient, placement — and every layer must keep text readable.**
